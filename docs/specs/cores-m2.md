# Spec: Milestone 2 cores

Status: draft (Milestone 2, package 1)

## Purpose

Build and package the libretro cores for the Milestone 2 systems from pinned
upstream sources, test each one against our own test ROMs, and let the game
session pick the right core per system (game-session.md).

## Cores

| System | Core | Library (Android) | License | Build |
| --- | --- | --- | --- | --- |
| GB, GBC, GBA | mGBA 0.10.5 | `libmgba_libretro.so` | MPL-2.0 | `cores/mgba/build.sh` (CMake) |
| NES | FCEUmm | `libfceumm_libretro.so` | GPL-2.0-or-later | `cores/fceumm/build.sh` |
| SNES | bsnes (libretro fork) | `libbsnes_libretro.so` | GPL-3.0-only | `cores/bsnes/build.sh` |
| Genesis | open, see below | | | |

FCEUmm and bsnes ship their own `Makefile` (host) and `jni/Android.mk`
(Android); `cores/libretro-make.sh` drives both from a pinned commit, so the
build is the upstream one with no patches. Every script takes
`<host|android-arm64-v8a|android-x86_64> [out_dir]` and writes
`<name>_libretro.{so,dll,dylib}`.

The Android plugin's Gradle task runs every script for each ABI and packages
`lib<name>_libretro.so`. Objects stay under `cores/build/obj`, which CI caches,
so unchanged cores rebuild in seconds.

## Genesis

BlastEm, the earlier default, has an x86-only 68000 recompiler and does not
build for ARM, so it cannot run on phones or handhelds. Genesis Plus GX and
PicoDrive are banned. The commercial-safe candidate that runs on ARM is
ClownMDEmu (AGPL-3.0-or-later). AGPL code can be combined with our GPL-3.0
app, but the combined app would carry AGPL's network clause. That makes this
the user's decision (CLAUDE.md §9); until then Genesis games show the
missing-core message.

## Test ROMs (ours, GPL-3.0-or-later, generated by script)

- `host/tests/roms/nes/make_rom.py` → `test.nes`: NROM, battery PRG RAM. The
  backdrop is black, white while A is held, red every 64th frame; each Start
  press increments `$6000` (battery RAM).
- SNES: a matching ROM follows in the same package.

## Acceptance tests

- Host golden tests per core (`host/tests/golden/<system>.txt`): idle and
  A-pressed runs give fixed frame hashes; the A-pressed frame differs from idle.
- Save-state round trip per core (`roundtrip`), like `roundtrip_gba`.
- CI builds every core for linux-x86_64, linux-aarch64, macOS arm64 and both
  Android ABIs; the APK contains all three libraries.
- The game session lists `nes` and `snes` as playable systems.
