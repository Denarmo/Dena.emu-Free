# Spec: Nintendo 64

Status: draft (Milestone 3, package 4)

## Core

- Mupen64Plus-Next libretro port (GPL-2.0; bundled GLideN64 GPL-2.0, parallel
  RSP/RDP MIT, xxHash BSD-2-Clause, zlib) at a pinned commit, built by
  `cores/mupen64plus/build.sh` for `android-gles3` and packaged as
  `libmupen64plus_libretro.so`.
- arm64-v8a only (the dynarec is aarch64; other ABIs have no N64).
- Renders through the libretro HW path (docs/specs/hw-render.md, GLES 3).
- No BIOS needed.

## Library

- Imports as system `n64` ("N64"): `.z64`, `.n64`, `.v64`.
- Box art from the "Nintendo - Nintendo 64" index (CRC of the file as stored).

## Controls

- RetroPad mapping used by the core: N64 A = RetroPad B, N64 B = RetroPad Y,
  Z = L2, L/R = L/R, Start, analog stick = left stick, C buttons = right stick.
- Built-in skin: touch thumbstick, A, B, C-up/down/left/right, L, R, Z,
  Start, menu.
- Touch thumbstick: tilt is the offset from the stick's centre over its
  radius, zero inside a 12 % dead zone, rescaled to reach 1 at the edge. A
  finger that starts on the stick keeps driving it when it leaves the frame.
  Tilt goes to the core over `dena_touch_analog` (dart:ffi), -0x7fff..0x7fff.
- C buttons tilt the right stick fully in their direction.
- Gamepads: with analog mode on (`setAnalogMode`, set for N64), the left and
  right sticks pass through as analog (12 % dead zone) instead of acting as a
  D-pad; the hat still drives the D-pad.
- N64 games use Z (L2), so a held L2 does not rewind.
- Imported `.deltaskin` N64 skins: a `thumbstick` item becomes the left stick;
  input names `a`, `b`, `z`, `cUp`… are renamed to the RetroPad names above.
- Cheats: GameShark (`XXXXXXXX YYYY`).

## Acceptance tests

- Import rules: `.z64`/`.n64`/`.v64` detect as N64.
- Touch: dead zone reads zero, full tilt reads 1, a dragged-off finger keeps
  the stick, C-up tilts the right stick up.
- Delta skin: thumbstick and renamed inputs parse.
- Host: `dena_core_set_analog` reaches the core's `input_state` (test core
  moves its square with the left stick).
- Kotlin: analog scaling and analog mode keep the stick off the D-pad.
- Golden: built-in N64 skin at phone, 640×480 and 720×720.
- On device (human checkpoint, no rig yet): a homebrew N64 ROM boots and the
  stick moves the player.
